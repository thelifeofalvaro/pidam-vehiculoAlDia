# BBDD en Supabase
La base de datos se ha implementado mediante Supabase, utilizando PostgreSQL como motor relacional.

La estructura de datos ha sido definida mediante scripts SQL versionados en el repositorio, lo que permite mantener un control de cambios y reproducibilidad del sistema.

Se han implementado políticas de seguridad mediante Row Level Security (RLS), garantizando que cada usuario solo pueda acceder a sus propios datos.

Asimismo, se ha utilizado el sistema de almacenamiento de Supabase para la gestión de archivos adjuntos asociados a las intervenciones.
